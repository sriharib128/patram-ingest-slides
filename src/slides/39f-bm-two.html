Finished. Which stages have finished this page. It fills up as the page moves through the graph.
Ready. Which stages may start on this page: it is now waiting in their queue.
A new page starts with nothing finished (0) and only Understand ready (1), because it is the first stage.

Each page gets two such rows, so two numbers. The first is Finished: which stages have finished this page. It starts empty and fills up as the page moves through the graph.

The second is Ready: which stages are allowed to start on this page, meaning the page is now waiting in that stage's queue. These two rows are the entire record.

In the DB it is one row per page: the page, the Finished number and the Ready number. A new page starts with Finished at 0, nothing done, and Ready at 1: only seat 0, Understand, may start. When a page has finished its last stage the row is deleted, so the record only ever holds pages that are in flight, not the whole dataset.
