A seat number per stage. Every stage in the graph has a seat: its position, counted from 0. The record has one switch for each seat. They all start off.
A switch on means yes. Here the answer is yes for Understand and Text, and no for Layout and Grounded Q&A.
A row of switches is one number. Seat 0 is worth 1, seat 1 is worth 2, seat 2 is worth 4, and so on. Add up the switches that are on. This is called a bit mask.

Every stage in a graph gets a position, like a seat number: Understand is seat 0, Text is seat 1, Layout seat 2, Grounded Q&A seat 3. For each page, the record has one switch per seat. A switch is a bit: it is either 0 or 1, off or on. At the start they are all off.

A switch that is on means yes for that stage. This row says: yes for Understand, yes for Text, no for Layout, no for Grounded Q&A. We will say what the question is on the next slide.

The useful trick is that a row of switches can be stored as one ordinary number. Give each seat a value: seat 0 is worth 1, seat 1 is worth 2, seat 2 is worth 4, seat 3 is worth 8. Add up the switches that are on, 1 plus 2, and this row is the number 3. That is all a bit mask is: a row of switches kept as a single integer. It is tiny, it is cheap for the DB to store, and the DB can update one switch without touching the others.
