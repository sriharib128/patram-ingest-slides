How the engine runs a graph

When the sweep lets a stage start

The sweep’s check. Each waiting stage has a row of the inputs it needs. Keep only those switches that are also on in Finished (third row). Here Layout is missing, so Grounded Q&A waits.
Layout has finished. Every needed switch is now on in Finished, so the third row matches the first. The stage may start.
Either one is enough. Write a question takes a table or a chart, never both. One needed switch on is enough, so it starts as soon as the chart is finished.

Here is exactly what the sweep checks. For every stage that has several inputs, the engine keeps a row of the inputs it needs. Grounded Q&A needs Text and Layout: seats 1 and 2, which is the number 6. The sweep takes the page's Finished row and keeps only the switches that are also needed. In the code that is a bitwise AND: Finished AND Needs. Here the page has Understand and Text finished, number 3. Keeping only the needed switches leaves Text alone. The third row does not match the first, so Layout is missing and the stage waits.

After Layout finishes, Finished is 7. Keeping only the needed switches now leaves Text and Layout, which matches the needs row exactly. Every input is finished, so the stage may start. It does not matter which machine ran which input, or in what order.

The same row of switches handles the other rule, either one is enough. Write a question takes a table or a chart. A page is never both, so waiting for both would wait forever. For this kind of stage the sweep asks a weaker question: is at least one needed switch on? The chart finished, so yes, start now. Same record, same check, a slightly different question. This is why one mechanism covers every graph shape.
