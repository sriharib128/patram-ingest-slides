First, a small warm-up. Stage 1 finishes a page and has to make two writes to the DB: mark Stage 1 done, and mark Stage 2 ready. The machine can crash between the two, and then Stage 1 runs the page again.

Which order is idempotent, meaning safe to run again after a crash? Hands up for A: mark Stage 1 done first. Hands up for B: mark Stage 2 ready first.

A is not safe: Stage 1 says done, so nobody runs the page again, but Stage 2 never hears about it, and the page is lost. B is idempotent: Stage 1 is not marked done, so it runs again and marks Stage 2 ready again, and ready twice is still just ready. Same rule as saving before marking done in part two: hand it on first, mark yourself done last, and make every write safe to repeat.
