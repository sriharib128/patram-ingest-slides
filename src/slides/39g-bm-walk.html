How the engine runs a graph

Following one page through the graph

The number is the row added up, with seats worth 1, 2, 4, 8. Ready stays on once switched on.
Last stage finished: the row is deleted
1 · A page arrives. Only Understand may start, so only its Ready switch is on.
2 · Understand finishes. Its routing function says this is a text page, so it goes to Text and Layout at once. Their Ready switches go on, then Understand’s Finished.
3 · Text finishes, on node 3. Grounded Q&A needs both Text and Layout, and Layout is not finished, so it waits.
4 · Layout finishes, on node 7, some minutes later. Both inputs of Grounded Q&A are now finished, but nobody has told it yet.
5 · The sweep notices. A background process reads the records every few seconds. It sees both inputs finished and switches Ready on for Grounded Q&A.
6 · Grounded Q&A finishes, the last stage. The page is done, and its row is deleted from the DB.

Let us follow one page through a small graph, with the record on the right. Understand feeds Text and Layout, and Grounded Q&A needs both of them. Text runs on node 3, Layout on node 7, different machines.

One: a page arrives. Finished is 0, nothing is done. Ready is 1, only Understand.

Two: Understand finishes. Its routing function says this is a text page, so the page goes to both Text and Layout at once. The engine switches on Ready for those two stages, and last of all switches on Understand's own Finished. Watch the numbers: Finished becomes 1, Ready becomes 7, which is 1 plus 2 plus 4. Routing is immediate: it depends on what the page contains, and the stage hands the page straight on.

Three: Text finishes on node 3. Finished is now 3. Grounded Q&A needs both Text and Layout. Layout is not finished, so nothing starts. There is no message, nobody waits on a phone call. The record just says what is done.

Four: minutes later, Layout finishes on node 7. Finished is now 7. Both inputs of Grounded Q&A are finished, but nobody has told Grounded Q&A, because stages never talk to each other.

Five: that is the job of the sweep, a single background process. Every few seconds, five by default, it reads the records, asks for each waiting stage whether its inputs are finished, sees that they are, and switches on Ready for Grounded Q&A. The next slide shows exactly how it decides. Because it only reads the record, it does not matter which machine ran which input, or which finished first.

Six: Grounded Q&A runs and finishes. It is the last stage, so the page is complete and its row is deleted.
